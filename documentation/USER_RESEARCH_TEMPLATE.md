## 1. Interview Plan & Rules (From Project Specification)

- **Who to interview:** 5 people aged 60 or more (grandparents, relatives, or neighbors).
- **Duration:** 10 to 15 minutes per person in a calm, quiet setting.
- **Rules for a good interview:**
  - Ask **open questions** (not yes/no questions).
  - **Listen more than you talk.**
  - **Do not lead the answer** (let them share their own real words).
  - **Ask permission** before taking notes or photos.
  - Record each participant's name (or alias like P1), age, and interview date.

## 6. Task Analysis & User Flows

### Main Tasks (Aligned with Project PDF)

| # | Task | Who Performs It | Target Taps | Implemented in MediRemind |
| :---: | :--- | :--- | :---: | :--- |
| 1 | Open the app and see today's medicines | Elderly user | 1 | Welcome → **Start** → Home |
| 2 | Add a new medicine (name, time, dose) | Elderly user or helper | 6 or fewer | Home → **Add Medicine** → Name + Time preset + Save |
| 3 | Mark a medicine as "Taken" | Elderly user | 1 | 1-tap **Taken** on Home card OR on Reminder Alert |
| 4 | See the medicine history | Elderly user or helper | 2 | Tap **History** in bottom navigation bar |
| 5 | Get an alert when a dose is missed | Family helper | 0 (automatic) | Simulated Helper Alert preview in Screen 4 (full push/SMS planned for FYP) |

### Primary User Flow — Taking Medicine on Time

```text
[1. Open App (Welcome)]
         │  (1 tap: Start)
         ▼
[2. View Today's Medicines (Home)]
         │
         ▼
[3. Reminder Alert Appears (Name + Pill Picture + Sound)]
         │
         ├──► User presses HUGE green "Taken" button
         │           │
         │           ▼
         │    [4. "Well Done!" Confirmation Shown (+ Undo option)]
         │           │
         │           ▼
         │    [5. Saved in History as Green "✓ Taken"]
         │
         └──► User presses "Remind Me Later" or ignores
                     │
                     ▼
              [Simulated 10-Minute Re-Alert]
                     │
                     └──► If still missed → Logged as Red "✕ Missed" + Helper Alert Preview
```

### Secondary User Flow — Adding a New Medicine

```text
[1. Home Screen]
       │  Tap "+ Add Medicine"
       ▼
[2. Add Medicine Screen]
       │  Step 1: Type Medicine Name (e.g., Panadol)
       │  Step 2: Tap Quick Time (e.g., Raat 8:00 PM) or Time Picker
       │  Step 3: Select Dose (default: 1 Tablet) & Optional Pill Visual
       │  Step 4: Tap large "Save Medicine" button
       ▼
[3. Form Validation]
       ├──► Empty field? → Show clear red plain-language message (e.g., "Please write the medicine name.")
       └──► Valid? → Save to localStorage → Return to Home
                     → Show "Medicine saved!" toast with Undo button
                     → New medicine immediately visible on Home
```
